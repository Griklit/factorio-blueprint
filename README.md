# Factorio 蓝图库

Sequence[7]的Factorio个人蓝图合集

## 目录结构

| 目录 | 描述 | 内容 |
|------|------|------|
| `00-采集` | 原始资源生产、采集相关 | 矿机布局、Gleba 玉玛果/果冻果人工农场 |
| `01-能量` | 电力相关蓝图 | 锅炉、太阳能板、避雷针、供热塔、酸中和、核反应堆（4 核 480MW）、聚变反应堆 |
| `02-生产` | 某些中间产物的专项生产 | 冶炼、电路板/处理器、化工（高级石油/硫化/煤液化）、铀增殖（Kovarex） |
| `03-科技包` | 生产科技包 | ≈100/min、≈1000/min、≈10000/min 三种规模的科技包 |
| `04-超市` | 物品超市 | 自动配方超市（锁存/定时/随机）、插件生产、初期超市、星球特产超市 |
| `05-科研` | 研究中心 | 可堆叠实验室（普通/信号/生物/插件组合） |
| `06-均分器` | 传送带均分器 | raynquist的均分器库：1-N 至 9-N 均分器 + 更大规模（最大 128×128）|
| `07-传送带构型` | 各种纠结的传送带 | 多线编织、混色带、双侧配置、传送带编织 |
| `08-铁路` | 铁路系统 | 左行铁路（网格吸附/非网格）、2-4 列车站台、装卸货、机车车厢编组 |
| `09-电力与物流` | 电力与物流 | 电力网、无人机物流网（多种网格尺寸和吸附对齐） |
| `10-战斗` | 防御系统 | 城墙、机枪炮塔、激光炮塔、火焰炮塔、重炮等构型 |
| `11-飞船` | 太空平台相关 | 新地星平台、雷神星飞船、玄冥星飞船 |
| `12-升级&规划` | 升级与规划 | 升级规划器（传送带/机械臂/组装机/插件/信号塔各等级）、拆除规划器（树石/悬崖/铁路/信号/火车/掉落物/地皮/垃圾填埋） |
| `13-品质` | 品质系统 | 轻质框架法传奇升品 |
| `14-简易工具` | 简易工具 | 永久雷达、初期简易自动化、测试工具 |
| `15-其他` | 其他 | 雷神星分拣器、杂项记录 |
| `16-无用` | 无效益蓝图 | SOS 地板 |

## 使用方法

每个 `.json` 文件是 Factorio 蓝图字符串。将文件内容复制在游戏中点击 `导入代码` 后粘贴即可导入。

注意，Factorio原生就支持导入 json 类型蓝图，将其以一般蓝图同样的形式导入即可。

### 蓝图簿

目录中包含的 `_book-info.json` 文件是蓝图簿的元信息。
